# 감정 주제 웹사이트 (공모전 출품작)

## 프로젝트 개요
- **기간**: 2주  
- **팀 구성**: 총 3명 (본인: 웹 개발 전담, 기획/디자인 피드백 참여)
- **성과**:  
  - 국제 커뮤니케이션 공모전 **우수상**  
  - 대한민국디자인전람회 **특선**  
  - 디지털미디어디자인과 연합 PT **최우수작 발표 선정**

---

## 담당 역할 및 기여
- **웹 개발 전담**
  - HTML, CSS, Vanilla JavaScript를 활용해 **10페이지 이상 하드코딩**
  - 페이지마다 다른 **그리드 기반 레이아웃** 설계 및 구현
  - **반응형 웹 디자인** 적용 (다양한 해상도 대응)
  - **웹 표준 및 접근성** 준수 고려한 마크업 작성

- **협업 및 기획 참여**
  - 초기 기획 아이데이션, 디자인 피드백 제공
  - Git을 활용한 버전 관리 및 협업
  - 개발기간 2주라는 짧은 기간 내 효율적인 일정 조율

---

## 사용 기술 및 특징
- **HTML5 / CSS3 / Vanilla JavaScript**
- **Cursor AI** 보조 활용 → 페이지별 다양한 CSS 그리드 구현 효율화 및 script 페이지 로딩/부드러운 페이지 전환/
- **사용자 경험(UX) 중심 개발**: 가독성 높은 구조, 직관적인 인터랙션
- **웹 퍼블리싱 경험 강화**: 레이아웃 설계, 스타일링, 스크립트 작성 전반

---

## 트러블슈팅 및 개선 경험

- **이미지 최적화 문제**
  - 초기 기획에서 GIF 이미지 사용 요청이 많아 페이지 로딩 속도가 크게 저하됨
  - 모든 GIF를 **WebP 포맷으로 변환**하고, 무거운 이미지를 대상으로 **Lazy Loading 기법**을 적용
  - 그 결과 **페이지 초기 로딩 속도가 단축**되고, 스크롤 시 불필요한 네트워크 요청을 줄여 **UX 성능 개선** 달성

- **반응형 구현 부족**
  - 디자이너 측에서 반응형 디자인 시안을 제공하지 않아, 직접 레이아웃을 구상하고 **노트북 해상도까지 반응형 구현**
  - 발표 환경이 데스크톱이 아닌 노트북(HDMI 연결)임을 고려해 발표 환경에 최적화
  - 결과적으로 발표 시 어떤 해상도에서도 UI가 깨지지 않고 안정적으로 작동

---

## 얻은 점
- 제한된 시간 안에서 **기획 → 디자인 → 개발** 전 과정을 경험
- 프론트엔드 개발자로서의 **기술적 자신감** 확보
- 공모전 및 전람회 수상을 통해 **성과와 결과물의 완성도 검증**
- **실무 협업 방식** 에 대한 이해 확립
